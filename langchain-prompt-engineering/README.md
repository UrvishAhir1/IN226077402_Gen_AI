# LangChain Prompt Engineering

This project demonstrates how to build a reusable prompt generation system using LangChain.

## Overview

The notebook replaces hardcoded prompts with structured PromptTemplate and ChatPromptTemplate to generate dynamic prompts based on user inputs such as topic, audience, tone, and style.

## Features

- Dynamic prompt generation using PromptTemplate  
- Multi-input prompt handling  
- Prompt variations (teaching, interview, storytelling)  
- Chat-based prompting using roles  
- Input validation for robustness  
- Reusable prompt design  
- Prompt playground for testing multiple scenarios  

## Workflow

User Input → Validation → Template Selection → Prompt Generation → Output
